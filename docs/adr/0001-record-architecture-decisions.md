# 1. Record Architecture Decisions

Date: 2026-04-09
Status: accepted

## Context

We need to record significant technical decisions made on this project so that future contributors understand why things were built the way they were, and so we can revisit decisions when circumstances change.

## Decision

We will use Architecture Decision Records (ADRs) stored in `docs/adr/`, numbered sequentially, written in Markdown, one decision per file.

## Consequences

### Positive
- Decisions are documented and searchable
- New contributors can understand historical context
- Forces clear thinking before committing to an approach

### Negative
- Requires discipline to maintain
- Adds small overhead to the decision-making process
